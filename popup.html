How to use
1
Open a WPML translation page on ate.wpml.org
2
Click a field to make it active in the TinyMCE editor
3
Use the buttons injected into the editor toolbar:
AI Translate — current field only   AI Translate All — auto-advances through all fields
4
Fields are saved automatically. Use Stop to abort at any time.
Requires
OpenRouter API key + model configured in Settings.
All translation quality settings (system prompt) are also controlled in Settings.
